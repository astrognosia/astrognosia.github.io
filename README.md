# Astrognosia

A free night-sky trainer for astronomy olympiad practice — <https://astrognosia.github.io>

This repository is the published site: the app itself, `index.html`, as one
self-contained page that picks the phone or the desktop layout by itself, with
its photographs in `images/` and its icons beside it. It is built and pushed by
the app's own build; please don't edit it by hand.
